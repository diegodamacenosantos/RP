# RP

Material dos vídeos. Cada pasta é um vídeo, no formato `#número - título`, e guarda os arquivos usados nele. Os vídeos tratam de Node-RED, dashboard 2.0, Docker e automação residencial.

Algumas pastas são modelos reutilizáveis, como `Template_Dia_e_Noite`, `TermostatoDashboard2.0Node-RED` e `relogio dashboard 2.0`.
